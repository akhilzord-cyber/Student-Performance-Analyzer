\# Student Performance Analyzer



\## 📌 About the Project



Student Performance Analyzer is a beginner-level Data Science project

that analyzes students' academic performance using Python.



\## 🎯 Objectives



\- Calculate total marks

\- Calculate average marks

\- Assign grades

\- Find top-performing students

\- Analyze subject performance

\- Analyze grade distribution

\- Visualize student performance

\- Find relationships between subjects



\## 🛠️ Technologies Used



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn



\## 📊 Features



\### 1. Total Marks

Calculates the total marks obtained by each student.



\### 2. Average Marks

Calculates the average marks across all subjects.



\### 3. Grade Calculation

Assigns grades based on the student's average marks.



\### 4. Top Students

Identifies the top-performing students.



\### 5. Subject Analysis

Finds the average performance in each subject.



\### 6. Data Visualization

Creates graphs for:

\- Average marks by subject

\- Grade distribution

\- Subject correlation
